# 电商促销归因分析

## 分析目标
评估促销活动对关键业务指标（GMV、订单量、客单价）的影响，识别主要贡献因素。

## 分析步骤

### 1. 数据质量检查
- 排除退款、测试订单、异常数据
- 确认促销标记字段准确（is_promotion / promotion_type）
- 检查时间字段完整性

### 2. 基础指标对比
- 促销期间 vs 非促销期间的核心指标对比
- 同比/环比变化率计算
- 按渠道/品类/用户群的分层对比

### 3. 归因分析
- 使用相关性分析和归因分析工具
- 识别对 GMV 变化贡献最大的因素
- 控制季节性和长期趋势的影响

### 4. 用户分群差异
- 参与促销 vs 未参与促销的用户行为差异
- 新客 vs 老客的促销响应差异
- 高价值用户的促销敏感度

## 输出规范
- 每条洞察必须包含促销贡献百分比
- 方法说明需要标明是否控制了季节性因素
- 结论需区分"相关性"与"因果性"
- 建议应包含可执行的优化方向
