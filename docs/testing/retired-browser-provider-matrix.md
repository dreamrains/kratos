# 退役的浏览器与 Provider 矩阵

状态：自 2026-09-06 起停用，等待重新设计。

旧矩阵把日常 pytest、浏览器旅程、真实 Provider 调用、发布判断和审计材料耦合在一起，导致以下问题：

- 普通测试依赖验收脚本，测试边界反向耦合；
- 未替换的 LLM 路径可能等待网络或意外消耗调用；
- 大量批次脚本、冻结文件和结果文档掩盖了真正的产品回归；
- 离线、浏览器、Provider、暂存和生产证据容易被混为同一种“通过”。

因此，旧矩阵的可执行脚本、候选清单和批次报告不再保留。能够独立证明产品行为的确定性契约测试已迁回普通测试套件；本文件只保留设计边界，不保留可运行入口。

## 未来重建设计约束

新的浏览器或 Provider 验收体系必须满足：

1. 不进入默认 pytest，也不被日常回归导入；
2. 离线单元/集成、本机浏览器、真实 Provider、暂存和生产分别报告，不互相替代；
3. Provider 默认关闭，执行前冻结源码、模型、数据、预算和报告路径，并取得明确授权；
4. 所有运行使用隔离目录，禁止隐式重试、模型切换和补充调用；
5. 先定义用户旅程、观察点、判定标准和停止条件，再实现运行器；
6. 传输、调用计数、数据归属或安全边界异常时立即停止，界面或文案偏差只记录而不扩大执行范围。

在完成上述设计评审前，不恢复旧矩阵，不执行真实浏览器验收，也不执行真实 Provider 验收。
