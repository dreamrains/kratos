## 关键发现

1. **广度与深度全面碾压**：6 个 v2 死路/退化场景，v1 全部给出超预期结果——S1 超锚点（第 4 模型族+AIC）、S2 超 7/11 锚点（恒等式分解+偏相关）、S3/S4 是 v2 完全做不到的能力。
2. **数值可信性**：S1/S2 的可比数值与独立核算完全一致（纯幂律 0.188/-0.7166/0.9824）——**有工具在手时模型"算而不编"**，8/22 B 基线（无工具直连）的编造风险在真实工具循环中未复现。
3. **v1 的真实弱点（需修复清单）**：
   a. 确认门过度触发（S5：描述性排序被当高风险决策）——7 月线 M1/P8-③ 的修复正是此类，可借鉴
   b. 口径纪律缺失：S4 用日均/窗口口径得出"+17.8%/持平"，我的配对总额核算是 -30.7%——**两者是不同 estimand 都诚实披露了，但系统没有"口径选择标准+配对检验优先"的纪律**；这正是 v2 compile 合同的价值所在
   c. 图表数少于工具调用（S2 调 create_chart 9 次落盘 3 张——同题覆盖或失败未深究）
4. **意图体系实测正常**：闲聊 2s/知识问答 8s/无数据主动澄清——v2 缺失的 L0 层在 v1 是即战力。
5. **模型环境**：思考失控未发生（工具循环形态下 reasoning 正常释放；B 基线失控是无工具单轮形态）。
6. **速度**：单场景 2-5 分钟，含多轮工具循环——用户体验可接受。
